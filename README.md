# QAIDAO.github.io

QAIDAO 组织主页（GitHub Pages）。纯静态，无构建步骤。

- `index.html` — 首页，展示所有活动
- `loomq/` — LoomQ 量子接入平权计划赛题页（来自 QAIDAO/LoomQ-2026）
- `100-skills/` — 100 Skills 开放题题板。`index.html` 与 `preview.png` 原样复制自 QAIDAO/100-skills 的 `release/promo/`（由 `release/tools/build_promo.py` 生成），不要在这里手改：改生成器，重新构建后再复制过来。

新增活动：在 index.html 的 `#events` 里复制一张 `<article class="card">`，再新建一个同名目录放页面。
